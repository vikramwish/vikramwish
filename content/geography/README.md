# Geographic source

`land.geojson` is Natural Earth's 1:110m land dataset, downloaded from:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson

Natural Earth data is public domain:
https://www.naturalearthdata.com/about/terms-of-use/

The build converts these polygons into an equirectangular globe texture and deterministic SVG previews. Pins represent public city-level experience locations and user-specified places. New Zealand and India are explicitly country-level points rather than inferred cities. No pin represents a residential address.
